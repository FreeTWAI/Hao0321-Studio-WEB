## 在自由工坊的位置

[自由工坊](https://freetwai.com) 讓會員先完成定位、選擇公會並領取 Repo 技能書，再以供貨、商店、開源作品、行銷與小隊共同完成成果。

行銷與媒體公會可研究的品牌作品網站來源。 目前 fork 包含静態網站、作品／資源頁、素材與部分獨立 API／工具來源。

工坊尚未把它改為通用白標模板，也未授予重用所有品牌／影像素材的額外權利或部署新的網站。

工坊 Fork：上游產品／授權來源為 [Hao0321/Hao0321-Studio-WEB](https://github.com/Hao0321/Hao0321-Studio-WEB)；本次協作的 Issue／PR 送到 **FreeTWAI/Hao0321-Studio-WEB**，不是自動送往上游。

程式／內容入口：[index.html](index.html)、[site.css](site.css)、[site.js](site.js)、[works/](works/)、[resources/](resources/)。協作先讀 [CONTRIBUTING.md](CONTRIBUTING.md)，讓 Agent 讀 [AGENTS.md](AGENTS.md)；從[本倉 Issues](https://github.com/FreeTWAI/Hao0321-Studio-WEB/issues)認領、[查看既有 PR](https://github.com/FreeTWAI/Hao0321-Studio-WEB/pulls)避免重工。

保留 Hao 品牌與原始來源；重新發布品牌、圖片或影片前確認對應權利。此網站不是中央 Portal，不接會員密碼、資料庫或管理員憑證；原網站 tracking／外部 API 需另作整合評估。 跨 repo 的協定由[中央平台](https://github.com/FreeTWAI/freedom-platform)維護。
